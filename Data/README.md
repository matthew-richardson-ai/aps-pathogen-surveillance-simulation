# APS Data

This directory contains data used by the Autonomous Pathogen Surveillance
(APS) simulation project.

## Directories

### Raw

Original datasets obtained from external sources.

Raw datasets should not normally be committed to GitHub.

### Processed

Cleaned or transformed datasets generated from raw data.

### Synthetic

Datasets generated by the APS simulation environment.

### ReferenceGenomes

Complete pathogen reference genomes used for simulated genomic analysis.

Reference genomes should generally be downloaded locally using documented
accession numbers rather than stored directly in the Git repository.

Example:

- SARS-CoV-2 Wuhan-Hu-1
- NCBI RefSeq: NC_045512.2

### Samples

Small datasets that are safe and practical to commit to GitHub for
demonstration, testing, and development.

## Important

APS is a simulation-only undergraduate university project.

The data and models contained in this repository are not intended for clinical diagnosis, epidemiological decision-making, or real-world biosurveillance.
